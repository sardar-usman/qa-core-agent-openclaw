QA-Core · v0.2 · Architecture

From Manual QA → Agentic Test Generation

A multi-agent pipeline that drives a real browser, reviews its own work, and writes Playwright tests that have already passed once — before they leave the agent.

What it does
/explore <url>
Live exploration
Drive a real Chromium browser through a URL, transcribe the verified session as a Playwright spec.
/generate <story>
Story to spec
Single-shot generation from a user story or Jira ticket. Marked UNVERIFIED until executed.
/heal <spec>
Self-healing
Re-resolve selectors that broke against the live page with the same ladder as exploration. Each heal is confirmed to point at the same element. Deterministic, no model.
The pipeline
Per-host memory
Cached fingerprints under .qa-core/sites/ — observed intents, auth hints, cascade stats. Repeat runs reuse the cache.
Cost budgets
Hard USD ceiling per run with per-stage tracking. Prompt caching on three system blocks (rules + memory + plan).
Selector cascade
getByRole → label → testid → CSS. Cascade level tracked per assertion and reported to the Critic.

Stack & rationale
Stack
  • Claude via the Anthropic SDK — tool use, prompt caching, model routing across Opus / Sonnet / Haiku.
  • Playwright + TypeScript — Chromium / Firefox / WebKit / mobile projects, retries, traces.
  • axe-core for a11y assertions auto-injected on every spec.
  • OpenClaw as the channel layer (web UI, Telegram, slash-command routing, persona).
  • GitHub Actions running generated specs on every PR.
Why it matters
  • Verified tests, not generated tests. Every action in the spec ran live in a browser before transcription.
  • Self-healing keeps suites alive. When the UI changes, the agent repairs broken selectors and proposes the diff for review.
  • Memory compounds. Per-host fingerprints + prompt caching mean repeat runs are faster, cheaper, and more consistent.
  • Stakeholder-friendly. Optional CSV review checkpoint lets QA leads filter scenarios before the Explorer runs.
  • Measurable. Real eval numbers (pass-rate, flake-rate, cost-per-test) replace marketing claims.
